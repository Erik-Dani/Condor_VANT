# ADAS (Airborne data acquisition System)

Ideal inicial del proyecto: 

La idea inicial del proyecto consiste en desarrollar una aeronave tipo avión controlada mediante radiofrecuencia (RF), que además de permitir el control remoto de sus funciones básicas, por ejemplo: el despegue, vuelo y aterrizaje, también que cuente con diferentes sensores para obtener información sobre su estado y ubicación durante la operación.
El proyecto busca integrar en una misma plataforma el sistema de control de vuelo, la adquisición de información mediante sensores y la transmisión inalámbrica de los datos hacia una estación terrestre.
La aeronave contará inicialmente con sensores que permitan medir diferentes variables, entre ellas: Temperatura, altitud, presión, velocidad angular y giro.  La selección definitiva de los sensores dependerá de los requerimientos del sistema y de los componentes disponibles para su implementación.
Los sensores estarán conectados a un sistema electrónico encargado de adquirir sus señales. Dependiendo de las características de cada sensor, algunas señales podrán requerir etapas de acondicionamiento, como filtrado, adaptación de niveles, amplificación o protección, antes de ser procesadas por el sistema digital. De esta manera, el proyecto permitirá trabajar directamente con las diferentes etapas involucradas en la adquisición de señales físicas.
Un microcontrolador será utilizado como unidad central de adquisición. Este recibirá la información de los diferentes sensores, organizará los datos y preparará los paquetes que serán enviados mediante un enlace RF hacia una estación terrestre.
La estación terrestre tendrá como función recibir la información enviada desde la aeronave y mostrar las variables obtenidas. Se espera poder visualizar, por ejemplo, la posición y altitud del avión, su temperatura, aceleraciones y variables relacionadas con su alimentación eléctrica. Además, los datos podrán ser registrados para conservar un historial de las pruebas realizadas.
El objetivo durante esta primera etapa no será realizar análisis avanzado de los datos ni implementar inteligencia artificial. Debido al tiempo y a la carga académica disponible, el alcance se concentrará en lograr que la aeronave pueda censar diferentes variables y transmitirlas correctamente a una estación terrestre, además de permitir su control remoto durante las pruebas.

2. Motivación
La motivación del equipo para desarrollar este proyecto surge del interés por trabajar posteriormente en una plataforma aérea que pueda ser utilizada para monitorear cultivos en diferentes regiones de Colombia, especialmente en lugares donde el acceso terrestre es complicado debido a la topografía montañosa.
La idea de fondo es que, en un proyecto futuro, una plataforma aérea más avanzada pueda recorrer diferentes zonas y recopilar información mediante sensores y cámaras. Estos datos podrían posteriormente ser utilizados para desarrollar herramientas de análisis y Machine Learning, con las que sea posible estudiar cultivos, identificar patrones, clasificar diferentes tipos de vegetación o detectar posibles enfermedades.
Sin embargo, desarrollar directamente una plataforma con todas estas capacidades tendría un alcance demasiado amplio para el tiempo disponible en el proyecto actual. Por esta razón, se decidió comenzar con un proyecto más concreto: un avión controlado mediante RF que permita adquirir y transmitir datos desde una plataforma aérea.
La intención es que este proyecto sirva como una primera experiencia en la construcción de la infraestructura necesaria para recolectar información desde una aeronave. Aunque durante este semestre no se realizará el procesamiento avanzado de los datos ni la implementación de modelos de Machine Learning, la información recolectada y la experiencia obtenida podrán servir como base para futuros proyectos orientados al monitoreo agrícola.

# Condor VANT.

Ideal inicial del proyecto: 

La idea inicial del proyecto consiste en desarrollar una aeronave tipo avión, llamada Cóndor – VANT, controlada mediante radiofrecuencia (RF), que además de permitir el control remoto de funciones básicas como: Despegue, vuelo y aterrizaje, cuente con diferentes sensores para obtener información sobre su estado durante la operación. El proyecto integra en una misma plataforma el control de vuelo, la adquisición de información mediante sensores y la transmisión inalámbrica de los datos hacia una estación terrestre.

El control de vuelo se resuelve con un sistema comercial de radiocontrol (transmisor y receptor a 2,4 GHz), que entrega directamente las señales de mando a los servos y al motor, de forma independiente al resto de la electrónica. Esto permite concentrar el desarrollo propio en la segunda parte del sistema: la adquisición y la transmisión de datos.

La aeronave cuenta con sensores para medir aceleración, velocidad angular, presión atmosférica (de la que se obtiene la altitud), distancia al suelo y tensión de la batería. Los sensores están conectados a un sistema electrónico encargado de adquirir sus señales; dependiendo de las características de cada uno, algunas señales requieren etapas de acondicionamiento, como adaptación de niveles o filtrado, antes de ser procesadas por el sistema digital. De esta manera, el proyecto permite trabajar directamente con las diferentes etapas involucradas en la adquisición de señales físicas.

Un microcontrolador es utilizado como unidad de adquisición a bordo. Este recibe la información de los sensores, arma los paquetes de datos y los transmite mediante un enlace de radiofrecuencia de largo alcance hacia una estación terrestre. En tierra, un segundo microcontrolador recibe esos paquetes, verifica su integridad y los entrega a una interfaz gráfica, donde se muestran las variables obtenidas: la altitud, la velocidad vertical, la aceleración y la tensión de la batería. Los datos válidos se registran además en un archivo, para conservar un historial de las pruebas realizadas.

El objetivo durante esta primera etapa no es realizar análisis avanzado de los datos ni implementar inteligencia artificial. Debido al tiempo y a la carga académica disponible, el alcance se concentra en lograr que la aeronave pueda censar diferentes variables y transmitirlas de forma confiable a una estación terrestre, además de contar con un control remoto robusto durante las pruebas.

2. Motivación

La motivación del equipo para desarrollar este proyecto surge del interés por trabajar posteriormente en una plataforma aérea que pueda ser utilizada para monitorear cultivos en diferentes regiones de Colombia, especialmente en lugares donde el acceso terrestre es complicado debido a la topografía montañosa. La idea de fondo es que, en un proyecto futuro, una plataforma aérea más avanzada pueda recorrer diferentes zonas y recopilar información mediante sensores y cámaras. Estos datos podrían posteriormente ser utilizados para desarrollar herramientas de análisis y Machine Learning, con las que sea posible estudiar cultivos, identificar patrones, clasificar diferentes tipos de vegetación o detectar posibles enfermedades.

Sin embargo, desarrollar directamente una plataforma con todas estas capacidades tendría un alcance demasiado amplio para el tiempo disponible en el proyecto actual. Por esta razón, se decidió comenzar con un proyecto más concreto: un avión controlado por radiofrecuencia que permita adquirir y transmitir datos de forma confiable desde una plataforma aérea. La intención es que este proyecto sirva como una primera experiencia en la construcción de la infraestructura necesaria para recolectar información desde una aeronave, antes de sumarle la complejidad de una plataforma orientada específicamente a la agroindustria.

Aunque durante este semestre no se realiza el procesamiento avanzado de los datos ni la implementación de modelos de Machine Learning, la información recolectada y la experiencia obtenida en la integración del control de vuelo, la adquisición de sensores y la telemetría podrán servir como base para futuros proyectos orientados al monitoreo agrícola.
